# Security policy

Bulwark is a security tool, so vulnerabilities in it matter. Please do not open
public issues for security problems.

## Reporting

Report privately through GitHub's "Report a vulnerability" (Security tab).
Include steps to reproduce and the affected version. You will get an answer
within 7 days.

## Scope

In scope: detection bypasses, leaks of provider keys or request data, auth
issues in the admin API, ReDoS in detectors. Out of scope: the inherent limits
of prompt-injection detection described in the design document.
